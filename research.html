Evidence-Based Hallucination Detection in LLMs

A retrieval-augmented verification framework for catching factual hallucinations in large language model output. Claims generated by the model are checked back against retrieved source evidence using semantic similarity, so a statement can be flagged when nothing in the retrieved context actually supports it.
