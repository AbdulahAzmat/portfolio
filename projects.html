Football Analytics Lakehouse

An end-to-end Bronze, Silver and Gold pipeline in PySpark on Databricks. Two complementary providers feed it: football-data.org for breadth (14,001 matches across 12 competitions) and StatsBomb for depth (267,255 ball-by-ball events). Loads are idempotent Delta merges with explicit schemas, quarantine for bad rows and an audit log, and Gold is a star schema for Power BI.

A full customer-segmentation and basket-analysis study on the Olist Brazilian e-commerce dataset. The Side-Quest Arcade

Four smaller builds that started as "I wonder if I can" and got finished anyway.

  • Console Snake
    C++ · Windows console

    A Programming Fundamentals course project. Snake with adjustable speed and a high-score file that persists between runs.

    Code ↗
  • Flick
    Python · aiohttp · HTTPS

    Swipe a photo or document up on your phone and it lands on your laptop, with a landing card, a glow coloured by file type and the file already on the clipboard. A Windows tray app with QR-code pairing over self-signed HTTPS, and nothing to install on the phone.

    Code ↗
  • Keyboard Sounds
    Python · pygame

    Plays a sound on every keypress, system-wide, with a small GUI to switch packs. The gunshot and mechanical-switch packs are synthesised from layered, filtered noise rather than sampled, with randomised variations so fast typing never loops one sample.

    Code ↗
  • Emotion Detector
    OpenCV · ONNX · CustomTkinter

    Reads emotion from a live webcam or a photo using a pre-trained FER+ model on the CPU. Detection runs on its own thread so the window never freezes, and a rebalancing option corrects the model's habit of guessing neutral for rare emotions.
